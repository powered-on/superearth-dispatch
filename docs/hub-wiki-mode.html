Why this mode exists

Devvit blocks outbound HTTP unless each hostname is declared in devvit.json and approved. When game API domains are denied, the app cannot fetch live order text from inside Devvit. Hub wiki mode keeps the same user-facing behavior by separating ingestion (external scheduled job) from display (Devvit reading Reddit-hosted wiki content).

Architecture

LayerWhat happens
External syncGitHub Actions (~45 min) fetches public data from api.helldivers2.dev and api.diveharder.com, writes JSON to r/superearth_dispat_dev/wiki/superearth-dispatch/orders-cache via OAuth wikiedit.
Devvit serverCron and mod refresh call getWikiPage on the hub page only. No external HTTP.
Devvit clientWebview calls /api/orders (Redis). No third-party URLs.
StoragePer-subreddit Redis cache on each install; hub wiki is the shared source of truth.

Transparency

  • The external sync workflow is defined in the public repository (.github/workflows/sync-hub-wiki.yml).
  • The hub wiki page is publicly readable; write access is limited to moderators on the hub subreddit.
  • No Reddit user data is embedded in the wiki payload or sent to game APIs.
