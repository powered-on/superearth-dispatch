HTTP Domain Exceptions — SuperEarth Dispatch

App: superearth-dispatch · Last updated: July 10, 2026

SuperEarth Dispatch is a read-only fan-made Reddit Devvit app that shows public Helldivers 2 Major Order text in a subreddit sidebar. It does not require game login, does not perform in-game actions, and does not send Reddit user data to external APIs.

Not affiliated with Arrowhead Game Studios, Sony Interactive Entertainment, or Reddit, Inc.

Why external HTTP is required

Devvit blocks outbound HTTP unless each exact hostname is declared in devvit.json and approved for the app. Major Order text is not available on Reddit — the server must periodically fetch public assignment data from an external API and cache normalized text in per-subreddit Redis for the sidebar widget and post webview.

How fetching works

ConcernBehavior
Who calls external APIsDevvit server code only (45-minute cron + moderator refresh). Never the visitor browser.
What the webview callsThis app’s /api/orders endpoint (Redis cache). No third-party URLs in client-side code.
Credentials / PII sent upstreamNone. Anonymous GET only. Community API identification headers (X-Super-Client, X-Super-Contact) for maintainer contact — no Reddit user IDs.
Data storedNormalized order titles, objectives, goals, and expiry metadata in Devvit Redis per installation.
Refresh rateDefault every 45 minutes; only sections enabled in mod install settings are fetched.

Domains declared in devvit.json

api.helldivers2.dev — required for Major Order

Purpose: Fetch current Major Order assignment text (title, briefing, task goals, expiry).

Why this host: Direct requests to api.live.prod.thehelldiversgame.com were previously rejected. The helldivers-2/api community project provides a documented /raw/ passthrough of the same public Arrowhead assignment payloads and asks third-party apps to use it instead of hitting Arrowhead production servers directly.

Endpoints used:

  • GET /raw/api/WarSeason/current/WarID
  • GET /raw/api/v2/Assignment/War/{season}

Source: src/server/services/ahgsClient.ts

Reddit S3 upload hosts — custom sidebar widget images

Purpose: Reddit custom sidebar widgets require an imageData URL. The app uploads a minimal placeholder image via Reddit’s widget image API; responses are served from Reddit-owned S3 buckets. Not used for order data.

  • reddit-uploaded-media.s3.amazonaws.com
  • reddit-uploaded-media.s3-accelerate.amazonaws.com
  • reddit-subreddit-uploaded-media.s3.amazonaws.com
  • reddit-subreddit-uploaded-media.s3-accelerate.amazonaws.com

Status: Already approved for this app.

Not currently requested: api.diveharder.com (optional third-party Personal Orders; install toggle defaults off). random.org is globally allow-listed and unused in the current build.
