S3 Cache Data Path — SuperEarth Dispatch

App: superearth-dispatch · Last updated: July 15, 2026

SuperEarth Dispatch is a read-only fan-made Devvit app that shows public Helldivers 2 Major Order and Personal Orders text in a subreddit sidebar. Order data is synced to a public JSON object on developer-operated Amazon S3; Devvit reads that object via approved S3 hostnames only.

Not affiliated with Arrowhead Game Studios, Sony Interactive Entertainment, or Reddit, Inc.

Architecture

LayerBehavior
External syncGitHub Actions (UTC :00/:10/…) fetches api.helldivers2.dev + api.diveharder.com → writes orders-cache.json to S3 via OIDC
Devvit serverCron (UTC :05/:15/…) + mod refresh fetch() the public S3 URL only
Webview/api/orders (Redis cache) — no third-party URLs in the browser
StoragePer-subreddit Redis cache; S3 object is the shared source of truth
